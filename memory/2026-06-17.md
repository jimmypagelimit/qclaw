## 教训：PowerShell 永远禁用（2026-06-17 06:42）⭐

- 张树再次指出：规则写了 PowerShell 永久禁用，但我一直在用
- **根因**：OpenClaw 默认 shell 是 PowerShell，我不主动切换就直接执行
- **后果**：`&&` 语法报错、引号转义不一致、`del` 行为不同……每次都踩坑
- **铁律重申**：
  - 所有 exec 命令必须用 Python 脚本，或 `cmd /c "..."` 包装
  - 永远不直接在 PowerShell 里跑命令
  - 这条已经写在 TOOLS.md 和 MEMORY.md 里了，不遵守是我的执行问题
