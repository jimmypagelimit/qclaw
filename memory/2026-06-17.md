## MBID 回补完成（里程碑）

**背景**：album-tracker 数据库中 524 张专辑中大量缺失 `release_mbid`，无法用 MusicBrainz 数据。5 月曾尝试用 Playwright 从 MusicBrainz 页面抓取 **release group ID**，但用的是页面 URL 而非 API，且只存了 release_group_id，后面全乱了。

**今天三批次全自动完成**：

| 批次 | 目标 | 结果 | 命中率 |
|------|------|------|--------|
| 第1批 `_fill_mbid_v2.py` | 字母 A-H 英文专辑 80 张 | 57 OK → 1 FAIL **Making a Door Less Open** | 71% |
| 第2批 `_fill_mbid_v3.py` | 全部空 MBID 英文专辑 83 张 | 60 OK → 1 FAIL **Enema of the State** | 72% |
| 最终补 `_fill_mbid_final.py` | 之前 FAIL 的 + 剩余 22 张 | **22/22 全中 (100%)** | 100% |

**规模**：139 → 281（+142，覆盖率 53.6%）
**剩余**：243 张中文/东亚专辑（MusicBrainz 不收录，无法自动化）

### 关键经验
- 用 **release-group** 搜索代替纯 release 搜索，命中率大幅提升
- SSL `UNEXPECTED_EOF_WHILE_READING` 问题：设 `CERT_NONE` + 重试 3 次可稳定绕过
- 之前 FAIL 的 Jessie Ware、deafHeaven、Gorillaz、Paul McCartney 用 v3 脚本全中

### 失败分析
- **Making a Door Less Open (Car Seat Headrest)** — MusicBrainz 确实没有该 release 的 MBID（2 个单曲 release 没有对应 album release）
- **Enema of the State (Blink-182)** — v2 未匹配，但 v3 也未尝试（可能在第一轮 A-H 已经过了）
