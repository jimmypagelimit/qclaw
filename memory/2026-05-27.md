## 13:29 专辑封面问题排查与修复

### 问题诊断
1. **封面文件存在但数据库字段为空**：
   - 封面文件已下载到 `\\10.0.2.4\qemu\原创计划\covers\`
   - 但数据库 `cover_image_url` 字段为 `None`
   - 导致 Web 界面无法显示封面

2. **Web 服务器路径问题**：
   - Web 服务器期望封面在 `album-tracker/public/covers/` 目录
   - 实际文件在 `\\10.0.2.4\qemu\原创计划\covers\`
   - 导致 HTTP 404 错误

### 修复步骤
1. **更新数据库 cover_image_url 字段**：
   ```python
   UPDATE albums SET cover_image_url = '/covers/538-Car_Seat_Headrest-Teen_of_Denial.jpg' WHERE album_id = 538
   UPDATE albums SET cover_image_url = '/covers/539-Waa_Wei-Hidden_Not_Forgotten.jpg' WHERE album_id = 539
   ```
   - 同时更新 `albums` 和 `albums_2026` 表
   - 提交 git 并推送

2. **复制封面到正确路径**：
   - 源：`\\10.0.2.4\qemu\原创计划\covers\`
   - 目标：`C:\Users\qujt\.qclaw\workspace\tasks\2026-05-12-long-term-project\album-tracker\public\covers\`
   - 使用 Python `shutil.copy()` 复制

3. **重启 Web 服务**：
   - 停止现有 node 进程
   - 重启 `node dist/server.js`
   - 验证 HTTP 200 响应

### 关键教训
- **album-tracker 封面文件路径规则**：
  - 封面必须放在 `album-tracker/public/covers/` 目录下
  - Web 服务器才能正确访问
  - `\\10.0.2.4\qemu\原创计划\covers\` 是备份位置，不是 Web 访问路径
  
- **数据库字段更新**：
  - `download-covers.js` 可能不会自动设置 `cover_image_url`
  - 需要手动更新数据库字段
  - 更新后需要重启 Web 服务才能生效
