## 封面补漏最终轮（~15:30-16:06）

### 发现的核心Bug：表ID不匹配 ⚠️

**问题根源：**
- `get_db_id()` 函数通过 Web API 搜索专辑，返回的是 **albums 总表**的 `album_id`
- 但实际这张专辑可能只在 albums_2026（或其他年份表）里
- albums_2026 里的 `album_id` 是独立的序列（38/88/79...），不等于 albums 表的 ID（447/487/478...）
- 当脚本尝试 `PUT /api/albums/447?table=albums_2026` → HTTP 404（albums_2026 里没有 ID=447）

**正确的表ID映射：**
| 专辑 | albums表ID | albums_2026表ID | albums_2024表ID |
