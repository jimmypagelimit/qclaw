## 08:47 三源合一规划 — Album Tracker × RYM × Pitchfork

### 规划文档
- 位置：`tasks/album-site/PLAN-TRI-MERGE.md`

### 核心设计：4+1 张卫星表，不动原表

| 表 | 用途 |
|---|---|
| `external_ratings` | 所有来源评分（一行=专辑×来源，UNIQUE album_id+source） |
| `external_metadata` | 补充元数据（一行=专辑×来源×字段） |
| `external_reviews` | 乐评元数据（来源/作者/日期/BNM，轻量） |
| `review_contents` | 乐评正文+翻译（一对多，review_id FK，lang+version） |
| `external_charts` | 榜单排名（支持不在库的专辑） |

### 关键决策：乐评和翻译不放字段
- 用户指出"翻译和乐评放到字段里合适吗"→ 不合适
- 乐评正文 2000-5000 词，放 TEXT 字段查询效率差、无法结构化
- 翻译需多语言+多版本+段落对照，字段无法满足
- 拆成 `external_reviews`（元数据）+ `review_contents`（正文，一对多）
- 翻译是独立记录，可迭代/回退/只加载元数据

### 执行路径
- Phase 0：建表+迁移（30分钟，不影响现有功能）
- Phase 1：批量回填（RYM 优先，103→400+）
- Phase 2：深度数据（PF 乐评/Charts/元数据）
- Phase 3：旧列清理（确认无依赖后删除 albums 表 rym_*/pitchfork_* 列）

### 统一查询视图
- `v_album_ratings`：一张专辑所有来源评分一行展示，含标准化百分制
- `v_rating_conflicts`：不同来源评分差异大的专辑

## 08:47 三源合一规划 — Album Tracker × RYM × Pitchfork

### 规划文档
- 位置：`tasks/album-site/PLAN-TRI-MERGE.md`

### 核心设计：4+1 张卫星表，不动原表

| 表 | 用途 |
|---|---|
| `external_ratings` | 所有来源评分（一行=专辑×来源，UNIQUE album_id+source） |
| `external_metadata` | 补充元数据（一行=专辑×来源×字段） |
| `external_reviews` | 乐评元数据（来源/作者/日期/BNM，轻量） |
| `review_contents` | 乐评正文+翻译（一对多，review_id FK，lang+version） |
| `external_charts` | 榜单排名（支持不在库的专辑） |

### 关键决策：乐评和翻译不放字段
- 用户指出"翻译和乐评放到字段里合适吗"→ 不合适
- 乐评正文 2000-5000 词，放 TEXT 字段查询效率差、无法结构化
- 翻译需多语言+多版本+段落对照，字段无法满足
- 拆成 `external_reviews`（元数据）+ `review_contents`（正文，一对多）
- 翻译是独立记录，可迭代/回退/只加载元数据

### 执行路径
- Phase 0：建表+迁移（30分钟，不影响现有功能）
- Phase 1：批量回填（RYM 优先，103→400+）
- Phase 2：深度数据（PF 乐评/Charts/元数据）
- Phase 3：旧列清理（确认无依赖后删除 albums 表 rym_*/pitchfork_* 列）

### 统一查询视图
- `v_album_ratings`：一张专辑所有来源评分一行展示，含标准化百分制
- `v_rating_conflicts`：不同来源评分差异大的专辑
