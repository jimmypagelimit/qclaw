## MusicBrainz 调研最终结论（21:57）

### 完整测试结果
- Python urllib/requests → `SSL: UNEXPECTED_EOF_WHILE_READING`
- Windows curl (Schannel) → `schannel: failed to receive handshake`
- **结论：不是 Python 专属问题，是 Windows TLS 栈与 MusicBrainz CDN (Fastly) 不兼容**
