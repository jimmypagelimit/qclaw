## 经验教训

### 1. 翻译不要用外部 API
- **问题**：GLM API 网络不稳定，经常超时，浪费时间
- **教训**：我自己就能翻译，不需要调用外部模型
- **改进**：以后翻译直接我自己来，不调 GLM/DeepL 等任何 API

### 2. 歌词来源单一
- **问题**：只用了 AZLyrics，部分歌曲没有或被反爬
- **教训**：应该准备多个来源
- **改进**：
  - AZLyrics（主）
  - Genius（备选，但需处理 Cloudflare）
  - Musixmatch（备选）
  - 用户手动提供（兜底）

### 3. 反爬处理
- **问题**：AZLyrics 有时会返回验证页面而非歌词
- **教训**：应该检测返回内容是否为真实歌词
- **改进**：检查 `DOCTYPE html`、`recaptcha`、`request for access` 等标记，识别反爬页面

### 4. 飞书通知
- **问题**：长任务完成后忘记发飞书通知
- **教训**：用户期望及时收到结果通知
- **改进**：长任务完成后主动发飞书告知结果

### 5. Git push
- **问题**：本地 commit 了但没 push，需要用户在场输入密码
- **教训**：应该配置 SSH key 或 token
- **改进**：配置 Git 自动认证，实现无交互 push

### 6. 歌词文件保存
- **问题**：第一次跑的时候没正确保存歌词文件
- **教训**：应该在抓取的同时立即保存，不要依赖后续流程
- **改进**：抓取 → 翻译 → 保存 三步合一，每首歌独立保存
