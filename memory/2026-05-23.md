## 16:15 网易云音乐命令行工具调研

**需求**：命令行版网易云音乐，需支持登录 + 下载 NCM 文件（加密格式）

**搜索结果**：
- `netease-dl`：pip 安装，支持登录后下载私人歌单，但下载的是解密后的 MP3/FLAC，不是 NCM
- `MusicBox`：Python CLI 客户端，支持登录/听歌/歌词，但不下载 NCM
- `ncmdump`：不是下载器，是把已下载的 NCM 转 MP3 的工具

**关键发现**：
- NCM 是网易云加密格式，官方客户端下载时才生成
- 要命令行拿到 NCM，需要模拟官方客户端的下载接口（需要登录态 + 解密 key）
- 目前没有现成的开源工具可以直接下载 NCM 原文件

**待确认**：用户想要的是下载 MP3/FLAC（用 netease-dl 即可）还是真正下载 NCM 原文件（需要抓官方接口，比较复杂）
