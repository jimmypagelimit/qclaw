- DNS 解析正常（musicbrainz.org → 142.132.241.153）
- TCP 443 可连接，但 TLS 握手立即失败（SSL EOF error）
- 所有 Python SSL 方案（urllib/httpx/requests）均失败
- curl.exe 也失败（SSL connect error）
- httpbin.org 等其他 HTTPS 站正常，只有 musicbrainz.org 和 anydecentmusic.com 异常
- **判断：网络层对 musicbrainz.org 做了 TLS 阻断**
