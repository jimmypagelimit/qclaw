
## 匿名旅行者数据提取方法总结（09:31）

### 核心流程（已验证成功）
1. **Playwright启动浏览器** → `playwright.chromium.launch(headless=False)`
2. **visit首页** → 获取session/cookie（必需，API直调返回空）
3. **键盘输入搜索词** → `page.type('input[placeholder]', query, delay=150)`
4. **监听XHR响应** → `page.on('response', lambda r: responses.append(r) if 'quick_search' in r.url else None)`
5. **提取JSON** → `response.json()` 中获取搜索结果
6. **获取详情** → `page.evaluate('fetch("/api/meta/album/{at_id}")')`

### 关键规则
- **短词(<4字)搜不到** → 必须用完整专辑名
- **曲目标题格式** `"1.曲名"` → 需去数字前缀提取歌名
- **无时长数据** → duration字段缺失，置NULL
- **郭佳短评** → rocknuts[].content字段
- **评分** → rating_anon字段，满分100

### 数据库写入
- 描述：风格 + 郭佳短评 + 外部ID
- 曲目：source='anontraveler'
- 评分：写入 external_ratings 表（score_scale='100'）

## 歌词路径存储方案（上线完成）

### 背景
之前 Web 界面的歌词加载靠实时目录匹配（扫描 `lyrics-expert/lyrics/Artist/Album/` 目录，在文件名和曲目名之间做 fuzzy match），每次请求都要做 I/O 扫描 + 字符串匹配，慢且不稳定。

### 改动
1. **数据库** — `tracks` 表新增两列：
   - `lyrics_text_path` TEXT — 纯文本歌词文件路径
   - `lyrics_lrc_path` TEXT — 时间戳歌词文件路径

2. **批量回填** — `_fill_lyrics_paths.py`
   - 遍历所有 `lyrics` 目录，按 artist→album→track 三层匹配
   - 精确匹配 + 前缀 fallback
   - **回填结果**：3175/4958 首（64%）成功匹配

3. **API 改造** — `server.ts` 歌词端点重构
   - **第一优先**：读数据库 `lyrics_text_path` / `lyrics_lrc_path` 字段 → 直接 `readFileSync`
   - **fallback**：对于无路径的专辑，降级到原来的目录扫描方案（兼容未处理的专辑）
   - 编译无报错，测试通过（Lennon - Imagine 和 CSH Twin Fantasy 都正常返回）

### 效果
- 已处理专辑的歌词加载：目录扫描耗时降到接近 0
- Web 服务已重启（pid 2664）
- Git 提交受阻：stale lock 文件卡住，稍后处理

### 临时脚本（可删除）
- `_fill_lyrics_paths.py`
- `_patch_server_lyrics.py`
- `_test_lyrics_api.py`

### 问题确认
- 嘎调-嘎调(id=35136) ✅ 网易云有
- 东京酒吐座-Remains(id=370393422) ✅
- 葬尸湖-冬霾(id=3070021) ✅
- 施鑫文月-灰太阳(id=263245626) ✅

### 关键发现：网易云歌词获取
- `/api/album/{id}` 需要登录，返回 code=-462
- **绕过方案**：专辑页 SSR HTML 包含曲目 id（正则提取 `"id":(\d+),"name":"([^"]+)"`）
- 提取 song_id 后调 `/api/song/lyric?id={song_id}` 可获取歌词（song 级别不需要登录）
- 前端显示仍然需要 session，但 `opencli browser work eval` + `credentials:'include'` 可绕过

### 修复结果
- **灰太阳** `施鑫文月-灰太阳`：8/8 首 ✅ 全部补全（日语/英语注音歌词）
- **嘎调** `嘎调-嘎调`：10/12 首 ✅（2首器乐无歌词）
- **葬尸湖-冬霾**：未处理（标题包含特殊字符"尸"→"屍"/"殭屍"）
- **东京酒吐座-Remains**：未处理（日文专辑名编码差异）

### 关键技术：浏览器 eval 获取登录态 API
```
opencli browser work eval "fetch('/api/...', {credentials:'include'}).then(r=>r.json()).then(d=>JSON.stringify(d))"
```
- `credentials:'include'` 自动携带浏览器 cookies → 绕过登录限制
- 适用于需要登录 session 的 API（网易云、知乎等）
- 比 Playwright 方案更轻量：不需要 launch 新浏览器
