## 音乐术语：低速原抓（21:48补充）

- **低速原抓** = CD 抓轨圈行话，以 1x/2x 低速 + 多次校验提取音轨，确保最高保真度
- 与"高速直拷"相对：低速抓错少，高速抓可能爆音跳帧
- 发烧友/收藏者标注质量的术语
