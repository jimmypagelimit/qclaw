1. 查出可疑 MBID（同一 MBID 对应多个不同艺人或 >3 个专辑）
2. 还原为 NULL
3. 重新用严格评分（MIN_SCORE=50）补全
4. 低于阈值的打 WARN 日志，不写入

**脚本状态**：`_fix_mbid_dup.py` 已写好但尚未执行（session 在写脚本后 compact）

**教训**：
- MBID 是唯一标识符，写错比不写严重10倍——污染数据库后续所有关联查询全部失效
- 批量写前必须先验证：至少手动跑 5-10 个样本确认逻辑正确
- 最低分数阈值必须有，不能有任何 fallback 写入逻辑
