## 技术讨论

### 大模型输入 token 与计算量
- 预填充阶段(Prefill)复杂度 O(n²)，输入越长计算量越大
- 生成阶段单步前向传播计算量相近（利用 KV cache）
- 长 context 明显慢是因为预填充占大头（TTFT）

### Dify 技术讨论
- Question 节点：暂停状态→存库→等待→恢复执行
- 客户端通过 SSE 接收"需要输入"事件
- 用户回答后调用 resume API 继续执行
- Dify 原生不支持主动推送消息到用户
- 推送需借助飞书/企微 Bot，Dify 只负责生成内容
