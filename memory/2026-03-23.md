- 配置清华镜像源
- 安装 git、vim、wget、tree、unzip、zip
- 安装 rsync、findutils、coreutils
- 安装 make、pkg-config、diffutils
- 安装 grep、sed、gawk、less、file

### Shell 配置
- 安装 zsh 5.9
- 安装 oh-my-zsh
- 配置 zsh-autosuggestions 插件（命令自动补全）
- 配置 zsh-syntax-highlighting 插件（命令语法高亮）
- 设置 zsh 为默认 shell

## 配置记录

命令执行优先级：
1. MSYS2 — `C:\msys64\msys2_shell.cmd -defterm -here -no-start -mingw64 -c "命令"`
2. Git Bash — `C:\Program Files\Git\bin\bash.exe -c "命令"`
3. CMD — `cmd /c "命令"`
4. PowerShell — 最后选项，尽量避免

注意：PowerShell 中文路径乱码，尽量不用
