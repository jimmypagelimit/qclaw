4. 如果曲名在标题行（`<h2>曲名</h2>`），优先选 Digital Media release 页面
5. MB release-group 的 cover-art 链接格式是 `/release/xxx/cover-art`，需去掉 `/cover-art` 后缀

## 2026-06-15 09:05 歌词源调研完成

### 歌词库实测汇总
- **LRCLIB**: 英文首选，免费REST API，命中率100%，有LRC时间戳，无中文
- **网易云音乐**: 中文首选，HTTP API需Referer头，**有中文翻译歌词+时间戳**（最大发现）
  - 翻译质量不错（实测Fill In The Blank翻译水准良好）
  - 搜索: `GET music.163.com/api/search/get?s=关键词&type=1&limit=10`
  - 歌词: `GET music.163.com/api/song/lyric?id={song_id}&lv=1&tv=1`
  - 返回 `lrc.lyric`(原歌词) + `tlyric.lyric`(翻译歌词)，均有时间戳
  - 已知限制：搜索不精确，部分需手机绑定
- **LyricsTranslate**: 可爬取（web_fetch艺人页200OK），歌词在 `<div class="ltf">`，搜索页超时
- **Genius/Musixmatch**: CF拦截/403，需API key或CDP绕过
- **AZLyrics/ChartLyrics/OVH**: 全挂

### 最终歌词获取策略
- 英文 → LRCLIB（主力）
- 中文+翻译 → 网易云音乐（主力）
- 冷门补充 → LyricsTranslate（爬页面）
- 双语对照 → 网易云原歌词LRC + 翻译LRC按时间戳对齐
