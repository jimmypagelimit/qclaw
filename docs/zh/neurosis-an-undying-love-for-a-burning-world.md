# Neurosis — An Undying Love for a Burning World

> 评分：8.3  | BNM：是  |   | 2026年3月26日

---

大約一年前，[Neurosis](https://pitchfork.com/artists/3105-neurosis/)——重金屬下半個世紀最具影響力的樂隊之一，極端的同時也是可親近的和進取的——看起來已死。四十年來一直是樂隊鼓手的傑森·羅德（Jason Roeder）開始[發布神秘帖子](https://www.metalsucks.net/2025/01/30/jason-roeder-says-he-was-unexpectedly-fired-over-the-phone-by-sleeps-management/)，說要離開巡演、處理唱片、拆除設備。羅德很快澄清他已被[Sleep](https://pitchfork.com/artists/30405-sleep/)單方面解僱，但他似乎對旗艦樂隊的狀況也不那麼確定。他推測，成員們將以某種不確定的形式繼續下去，「有我或沒有我」。

距離 Neurosis[最近的一張專輯](https://pitchfork.com/reviews/albums/22476-fires-within-fires/)已過去近十年，那是第一張讓人感覺例行公事的專輯，但時間和精力都不是真正的問題。2019年，Neurosis 悄悄與聯合創始人斯科特·凱利（Scott Kelly）分道揚鑣——將他的家庭虐待和情感操縱，以及隨後的解雇低調處理，以尊重他家人對隱私的願望。當凱利最終[承認](https://pitchfork.com/news/neurosis-scott-kelly-admits-to-abusing-family-announces-retirement-from-music/)了這些傷害時，Neurosis 的其餘成員毫不留情。「通常，我們會將對精神疾病的公開坦誠視為勇敢甚至有效的，」樂隊[寫道](https://www.metalsucks.net/2022/08/29/scott-kelly-admits-to-family-abuse-quits-music-neurosis-responds/)。「只是在這裡我們不認為是這種情況。」此後他們看似老去的狀態感覺像是某部苦樂參半的 Neurosis 說唱史詩的橋段：切除癌細胞，然後仍然緩慢死去。

但就在羅德公開困惑於未來之際，Neurosis 的第二次生命正伴隨著他緩慢開始。2024年4月，亞倫·特納（Aaron Turner）——多產的 [Isis](https://pitchfork.com/artists/2122-isis/)、[Sumac](https://pitchfork.com/artists/32734-sumac/) 和 [Old Man Gloom](https://pitchfork.com/artists/30452-old-man-gloom/) 的主腦，也是 Neurosis 最傑出的後裔之一——首次與其餘四人一起排練。他和史蒂夫·馮·蒂爾（Steve Von Till）——Neurosis 昔日雙頭搭檔的另一半——一直以私人二重奏的形式一起創作和演奏。他們似乎在回味二十五年前的一個「老派」笑話：當時懷疑論者嘲笑「神經質崇拜」（Cult of Neur*isis*）是帶有過度優越感的前衛金屬。

距離首次全樂隊排練不到兩年，由新搭檔率領的五人版 Neurosis 在春分出人意料地發行了《*An Undying Love for a Burning World*》——在這樣一個對更新來說歷來吉祥的日子，瑞士人早已在此日火化雪人雕像。《*Undying Love*》是 Neurosis 二十年來——甚至可能是二十五年來——最好的專輯，來自一支足夠成熟而不會假裝生活最終不會在黑暗中結束的樂隊的明亮的、重生般的復出。這八首歌要求我們無論如何都要繼續活下去。

在 Neurosis 關於《*Undying Love*》的[首次採訪](https://music.apple.com/us/album/an-undying-love-for-a-burning-world/1882105289)中，馮·蒂爾告訴 Apple Music：專輯的引子——一段約一分鐘長的扭曲尖叫，關於我們如何與彼此、與我們自身的必死性失去聯繫——並非政治性的。他堅持說，這就是 Neurosis 一直以來寫作的內容。他是對的，但在基本正派已成為分裂問題的當下，他也錯了。

《*Undying Love*》讀起來像一份非刻意為之的、迂迴的宣言，其核心價值觀簡單來說就是尊嚴：團結勝過剝削、對鄰人的相互支持、理解對微小差異的自戀只會縮短已經太短暫的人生。這裡的語言如同滑到此時此刻般直白：死去的河流、流血的指尖、淤青的身體、破碎的土地、冰凍的屍體。但在迷幻藍調金屬的凱旋曲「Untethered」末尾——這首歌將過去、現在和未來壓縮進四分鐘引人入勝的時光——馮·蒂爾的尖叫始終值得我們向上或向前看，即使地平線上人滿為患：「尋求清晰天空的誠實一份……目光所及，電線上都是老鼠。」

新 Neurosis 的前進方式與舊版本至少在最佳狀態時如出一轍：他們將不太可能的元素無縫融合，贪婪地掠奪各流派，用作苦難與救贖之路上的鋪路石。「In the Waiting Hours」從一段優美但抑鬱的漂移滑向泥漿金屬風暴，「Seething and Scattered」從諾亞·蘭迪斯（Noah Landis）合成器和音序器塑造的狂熱恍惚轉向一個讓大多數數學搖滾樂隊臉紅的 反饋與鼓點總高潮。《*Undying Love*》永遠在展開中，總有一些新的精妙之處即將顯現。

展示這種技藝的是十七分鐘的壓軸曲「Last Light」。特納以對著工業貝斯地震咆哮開始，然後吉他和鼓進入，羅德那種耐心和規模感似乎因他演奏石頭金屬大作的經歷而煥然振奮。這裡有一段堪稱英雄的 riff、一個邪惡的噪音 breakdown、一個幽靈般的小合唱團，周圍的電路像蒼蠅一樣嗡嗡作響，還有一段緩緩上升的器樂拓展，讓你想起軍樂隊最初是為戰爭而非體育而生的。這是一部關於必死性的史詩，關於即使我們過著日常生活的同時，我們也存在於「死亡……一頭貪婪的野獸」的陰影之下。但在最後五分鐘，樂隊似乎在其中盡情歡愉，而非沉溺其中。Neurosis 被終極結局對此刻的意義所激勵。這個毀滅性的尾聲——全部是喧囂和鼓——聽起來像是凱旋，Neurosis 只是被再次嚎叫的行為和力量所驅動。

值得回顧那個現在已經成為現實的愚蠢舊合成詞：Neurisis。回到那個笑話還流行的年代，Neurosis 和 Isis 是雙雄並立：前者是一支剛達到磁性新頂點的老將樂隊，後者是短暫但輝煌的歷程也即將達到巔峰的新銳力量。彼時此刻，全樂隊合作是一股[大氣候](https://www.treblezine.com/in-the-fishtank-albums-guide/)——好壞參半——Isis 甚至與 [Aerogramme](https://pitchfork.com/artists/28-aereogramme/) 一起製作了一張專輯。我很高興他們避免了這一點；我擔心他們會相互抵消，成為[一些同儕](https://pitchfork.com/reviews/albums/9563-altar/)那樣的重疊波紋。

但這種延遲而意外的交匯完全是加成性的。特納及時到來，不只是幫助重啟了這支美國金屬機構，而是真正將其復活。而且 Neurosis 的其餘成員將他完全融入，不僅放任他對質感混沌和威嚴人聲的偏好，也讓他設計封面；他不只是一個替代品，而是一個新的引擎。「我們手指間的真實財富在溜走，」特納在「Mirror Deep」中部咆哮——這首歌如同任何美好生活一樣美麗而沉重。「當我們為死者計數。」Neurosis 還沒有進入那些失去的行列——對於一個燃燒中的世界來說，這是一種真正的、令人欣慰的喜悅。
