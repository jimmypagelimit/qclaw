# Feeble Little Horse — bitknot

> 评分：8.1  | BNM：否  |   | 2026年6月1日

---

高科技曾經是手工製作的。從二十世紀五十年代到七十年代，計算機用稱為磁芯的陶瓷環來存儲數據。這些磁芯由單個工人用導線串聯，形成一個整潔的功率和內存網格。發送到一個磁芯的電會感應相鄰導線，一個位的激活賦予其相鄰者力量。作為數據存儲方案，它很有效：每個磁芯即使斷電也能保留其數據。作為工藝品，它優雅，像一件織到一半的信息織物。這種交叉微小歷史節點的相互依賴系統被稱為巧合磁芯內存矩陣，最終簡化為「 core memory」。像許多語言和文化一樣，那個短語已從抽象漂移到具體，最終成為一個感覺完全不相關的隱喻——曾經被用來描述一段晦澀計算機科學歷史的詞語現在被用來指稱在童年時真的很喜歡某樣東西。像一塊數據碎片一樣，這個短語將其起源保存在深層存儲中，即使它被其內在的意義所驅動；儘管資本主義有著壓倒性的力量和影響力，事物總是向人類漂移回來。

《*bitknot*》在電路板上又插入了一個釘子。在 Feeble Little Horse 的第三張專輯——以及首次在創始成員萊恩·沃爾孔斯基（Ryan Walchonski）離開後——這支匹茲堡三人組使用塞巴斯蒂安·金斯勒（Sebastian Kinsler）製作節拍時留下的製作技巧和歌手 Lydia Slocum 的歌聲，將對大科技的尖銳批評纏繞在嘎吱作響的獨立搖滾周圍。雖然他們並未喪失那種讓2023年的《[*Girl With Fish*](https://pitchfork.com/reviews/albums/feeble-little-horse-girl-with-fish/)》感覺像是一個特別甜膩版本的 [Swirlies](https://pitchfork.com/reviews/albums/7674-cats-of-the-wild-vol-2/)式慵懶盯鞋搖滾的家庭魅力，但他們對聲音的掌控已戲劇性地增強了。《*bitknot*》中的歌曲比其前作更重、更醜、更 glitch 化。但它們也更可愛，充滿更多生命力和更多同理心。

這些組件可能很熟悉——聽起來像是通過一台開到最大聲的破舊齊尼思電視機播放的吉他、像九十年代民謠垃圾樂隊 Days of the New 那樣沉重的原聲掃弦、Slocum 那種褪色讀數式的人聲——但它們都被拉成了稍微不尋常的形狀。這剛好足以讓你措手不及；當你試圖弄清楚為什麼「Dior」的主要 riff 聽起來像是少了幾個音符時，Slocum 關於資本主義如何讓我們相互競爭的看法幾乎在不經意間滑入。像它挑戰的那些系統一樣，《*bitknot*》試圖重新連接你的思維和感受。

這些歌曲主要建立在骯髒的 riff 之上——它們那過載的污跡有時會遮蔽 Slocum 的聲音，讓專輯感覺像是《[*Psychocandy*](https://pitchfork.com/reviews/albums/11882-psychocandy-darklands-automatic-honeys-dead-stoned-dethroned/)》的有聲表親——所以堅持說這是你需要用好耳機聽的音樂感覺有點奇怪。雖然盯鞋搖滾的混沌水域中總是藏著沉沒的寶藏，但《*bitknot*》如此多的聲音細節都在支撐著創作，提升著歌曲的情感衝擊力。在「Doorway」的最初幾秒鐘，吉他 punch-out 打開專輯後，樂隊進入了一種自製的 [Stereolab](https://pitchfork.com/artists/3945-stereolab/) groove，而一個聽起來像口琴的遙遠吉他一直在旁邊泵動。「Paris」似乎從「Dior」的放射性塵埃中浮現，家庭度假的福佑景象被處理的風鈴聲和經過汽車的現場錄音所改變，在陽光下閃爍，變得超現實而略帶恐懼。甚至單個吉他音色也根據歌曲的敘事語氣設定；在糟糕的「DMT」（「死亡、金錢、科技」）中迴蕩的扭曲和聲圈子像一個生鏽的罐頭刀一樣在鐵皮上旋轉，彷彿它們在模仿互聯網撕裂我們以收穫其中內容的方式。

Slocum 的聲音纖細而柔軟，像覆蓋在你醫生檢查台上的紙。它的半透明性往往捕捉樂隊投射其上的光線：她在「Cradle」懶洋洋的下午迷霧中溫暖而發光，然後在「Shopping」的衝刺中成為眾多色彩中的一種。她有時似乎在行進中一半突然陷入懷舊而不沉溺其中——就像當你在講述一個故事並記起一個特別有趣的細節時，你知道你不能讓它拖累勢頭。「這東西燒柴油嗎？/我的國家就是我需要離開的，」她在「Cradle」中以日常的從容唱道。感覺這是正確的方法：此刻逃離美國生活的迫切可以既是緊迫的，也是聊起來有點無聊的。

聽別人唱這個一般也是無聊的，無論他們的專輯製作得多好。而且，可以肯定的是，這個世界最不需要的就是另一群在書架上放滿未讀 Verso 書籍的焦慮獨立搖滾客。讓《*bitknot*》的批評起作用——讓它感覺更像故事而不是批評——的原因在於這些歌曲理解「晚期」資本主義的邪惡不是抽象概念，而是這些概念對受其約束的人們生活所產生的影響。意思是：因為嫉妒你那個帥朋友在社交媒體上的表現而被點燃激情、被瓦解自我意識是很糟糕的。意識到整個東西被設計出來主要是為了讓馬克·扎克伯格更富有，這很屈辱。

 petty 嫉妒在《*bitknot*》中來回彈跳。「她就像我但更漂亮/這不公平，」Slocum 在「Shopping」中唱道，然後幻想著偷走那個漂亮女孩的手機去翻找她的 Ssense。在「Dior」中，她向某個獨立搖滾主唱發出了一個 kiss-off：「你不是大衛·伯曼/你不是科特·柯本。」歌手的身份不是重點——事實上他們的名字被消音了，像廣播裡的髒話——Slocum 的挫敗感來自於被逼迫到為了銷量而進行藝術之戰，以及那場戰鬥如何讓人表現得比實際的更大。她也把刀刃向內。「我沒有保險/但什麼都不痛/穿著 Ben Doctor，」她唱道，引用了這位獨立設計師的名字。這是一種承認：這個體制灌輸給我們的虛榮和消費是繞過它所創造的痛苦的一種方式；但也是對看起來和感覺良好的一種真誠的慶祝。她看不起醫生，但她在醫生的衣服上被看見。

快樂和壓力、個人欲望和集體操縱——這些本應對立的極點在《*bitknot*》上全部重疊，因為它們在生活中無法被分開。這是一張 harsh、刮擦的聲音讓甜美的人聲旋律聽起來更甜的專輯，在那裡那種精神善良可能閃爍但從不真正消失。《*bitknot*》遠非對我們科技資本主義統治兄弟的教條式揭露，它是一張富有同理心、專業編排的歌曲合集，它不以居高臨下的姿態看待我們這些在設計來讓我們悲慘的體系中努力感覺良好並創造一點美的人。對於 Feeble Little Horse 來說，選擇退出商業及其數百萬下游影響並不像說「我不喜歡那個，我不會那樣做」那麼簡單。終究，我們不責怪被射擊的靶子。
