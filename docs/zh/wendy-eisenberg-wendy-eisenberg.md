# Wendy Eisenberg — Wendy Eisenberg

> 评分：8.2  | BNM：是  |   | 2026年4月9日

---

[Wendy Eisenberg](https://pitchfork.com/artists/wendy-eisenberg/) 曾經只為他們的技藝寫情歌。他們版本的甜蜜情話？「告訴我我會寫下另一個完美的想法。」他們歌詞中的承諾是對一種創造生活的投入——通常本質上是一種孤獨的生活：「當我是藝術家的時候，我可以被愛，」他們在2021年的專輯《*Bent Ring*》中唱道。當他們用好奇的眼光轉向「情歌」時，主要是對其慣例皺眉。「當我寫小情歌的時候不要看我，這對我來說已經足够尴尬了，」他們唱道。「這是一種非常高級的折磨形式/在一個我討厭的流派裡寫一首歌。」我，呃，也愛你。

無論這位歌手兼詞曲作者和吉他手在過去半個五年瘋狂產出中發生了什麼其他事情，Eisenberg 顯然已經墮入了愛河。《*Wendy Eisenberg*》中的 Wendy Eisenberg 嶄新地無畏於情歌——或者至少對它們的宣言不再尴尬。他們以法醫般的好奇和壓抑的驚奇書寫關於新發現幸福的內容，彷彿在詳細描述一種奇異的植物種類。

Eisenberg 可能憎惡「我愛你」這個短語的部分原因是其中沒有什麼可以拆解，而拆解事物正是他們的風格。Eisenberg 的目光將大想法分解成數十個更小的想法，讓它們從你的理解中扭動逃脫。你可以稱這個過程為解構或陌生化，但一個更友好的術語可能只是仔細觀看。在這張新專輯中，Eisenberg 看得*非常*仔細。取這句歌詞，來自令人著迷的抒情曲「It's Here」：「某樣東西正在失去它的意義/有人正握著我的手/來吧，看我正在學習/需求中有舒適。」這不就是學會放下對自己不配那種糾纏不休的舊恐懼的*精確*聲音嗎？

沒有兩張 Eisenberg 專輯聽起來相同：他們做過分裂的爵士專輯、碾壓的搖滾史詩、班卓琴即興創作。在開採這片廣闊的新領地時，Eisenberg 轉向他們稱為「怪異鄉村解讀者」的音樂人——[理查德·道森](https://pitchfork.com/artists/32553-richard-dawson/)、[Mekons](https://pitchfork.com/artists/2730-mekons/)、[喬安娜·紐森](https://pitchfork.com/artists/3096-joanna-newsom/)。在「Old Myth Dying」中，他們模仿了紐森豎琴上的一個標誌性手法，將切分旋律線與直的四拍對置，產生了一種永不解決的夢幻張力。

Eisenberg 的作曲才智有一種近乎無情的品質，聚焦於平靜的感覺並使它們不安。「Vanity Paradox」閃爍的節拍感覺像是一次屏住的呼吸，一個緊張的肌肉，直到歌詞「這些舊傷/不配得的/告訴我這很重要」——這觸發了一股大調和弦的浪潮，它們似乎在現實中溶解著傷口。

這裡最好的三首歌——「Another Lifetime Floats Away」、「It's Here」和「Will You Dare」——是 Eisenberg 迄今最不設防的陈述。每一首的核心都是一首頌歌，一首奉獻曲——一首情歌。「Another Lifetime Floats Away」在童年記憶的超現實強度上徘徊。在一段詩節中，Eisenberg 在他們父親工作時躲藏；在另一段中，他們的母親為他們做早餐。在第三段中，他們二十歲了，在方向盤後面，大概是在開向或離開另一場演出。每段詩節都以 Eisenberg 歎息著專輯名稱結束，那種失去的感覺與其尖銳性一樣難以解釋。

但「It's Here」是專輯明顯的中心——它的核心，如果這個短語不會讓 Eisenberg 反胃的話。他們探索了一個關於吃掉森林的美德與模仿森林鳥類之間virtue的糾纏思維：也許這是一個隱喻，關於生活與努力再現它之間的差異。但在最後，Eisenberg 將這首歌濃縮成了一聲鳥叫，只有兩個字，重複著：「它在這裡。」踏板鋼琴在哭泣，一台 Wurlitzer 電子鋼琴在潺潺，而和弦在大小調之間徘徊。什麼「在這裡」？也許是浪漫的愛情，也許是對整個世界的熱愛——在它所有的脆弱之中。但那種氛圍——安靜的欣快、警覺、充滿期待的生機——傳達了 Eisenberg 需要我們知道的一切。
