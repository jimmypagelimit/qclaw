# V-Project 版本历史

## V7 — 深夜唱片内封（2026-10-19）

新增独立静态生成器 `_gen_batch_bg_v7.py`，不覆盖 V3。

- 尺寸仍为 1920×1080；封面位置仍为 x=180、y=265、550px 正方形。
- 哑光内封、右侧露出的黑胶、细密沟槽、定向反光与柔和接触阴影。
- 根据封面的色彩群提取环境光；白色、黑色占比过高时退化为中性色。
- 2026-10-19 配色修订：保留 V7 全部布局与唱片材质，提高主色保留率，加入大尺度柔焦封面色域，使主色与次色融入背景；右侧按统一比例压低 RGB 亮度，保留色相。
- 新增红/蓝封面色相响应及灰阶封面中性测试；修订前后对比见 `output/bg_v7/preview/color-comparison.jpg`。
- 同日再次按用户反馈修订：背景全幅统一使用专辑主色，取消右侧渐暗、局部多色云雾与叠字区亮度压缩；对称柔光变化仅 3%。新增左右背景平均 RGB 一致性测试；此修订取代上一条配色方案。
- 右侧 x≥1100 以低亮度留白为主，不烘焙专辑名、歌词、商标或额外文案。
- 封面在光影处理后原样贴入，不叠加颗粒、色温或反光。
- EXIF 朝向与透明图片处理；像素哈希作为随机种子，改文件名不影响输出。
- PNG 独立输出至 `output/bg_v7/`，支持 `--test` / `--input` / `--output`。
- 四张样张及 V3 / V7 对比见 `output/bg_v7/preview/`。对比左栏为已有历史文件，未重新生成或修改。
- `python3 -m unittest discover -s tests -p test_bg_v7.py -v` 验证封面像素、留白、确定性、旋转、损坏输入和防止覆盖输入。

### V7 旋转 MP4 分支（2026-10-19）

新增 `_gen_video_bg_v7.py`，复用统一主色静态 V7。封面/内封/背景/投影静止，盘标与唱片纹理顺时针转动，光源固定。默认 6秒/圈、30fps、1920×1080、无声 H.264 MP4；整数圈无缝循环，支持单张与歌单批量。成功后原子替换输出。新增动画不变量测试，静态+动画共7项测试通过；两张封面实际批量导出2/2成功。ffprobe核对1080p、30fps、180帧、6秒、H.264/yuv420p/BT.709及无音轨，解码帧核对封面与背景稳定、黑胶发生运动。旧 V3/V5/V6 及 V7 静态脚本不变。

### 版本命名说明

原 `_gen_batch_bg_v3.py` 内部自称“V4 精致版”，文件名沿用 V3；V5/V6 是已有动画脚本。此次新增版本使用 V7，避免与这些分支混淆。旧脚本和产物全部保留。

## V3 — 最终版（2026-06-27 定稿）

**定位**：V2 底子 + 动态配色（唯一改变）

**核心改变**：
- 右上角三个圆点颜色：从封面提取主色（非固定金色）
- 封面边框颜色：从封面提取主色（非固定金色）
- 所有其他参数与 V2 完全一致

**V2 参数（完全保留）**：
| 参数 | 值 | 说明 |
|------|-----|------|
| W, H | 1920, 1080 | 尺寸 |
| COVER_X | 180 | 封面左边距 |
| COVER_SIZE | 550 | 封面尺寸 |
| CD_BORDER | 16 | CD外圈宽度 |
| CD_LINE_COLOR | (60,50,64) | CD线条颜色 |
| CD_INNER_R | 55 | CD内圈半径 |
| CD_HOLE_R | 14 | CD中心孔半径 |
| DOT_RADIUS | 6 | 右上角圆点半径 |
| DOT_GAP | 30 | 圆点间距 |
| DOT_TOP | 30 | 圆点上边距 |
| VIGNETTE_STRENGTH | 0.75 | 正圆暗角强度 |
| RIGHT_FADE_END | 810 | 右侧渐暗结束位置 |

**动态配色算法**：
- NumPy k-means 聚类（k=3，5次迭代）
- 从封面缩放至 50×50 像素取样
- 选择最亮的聚类中心作为主色
- 回退值：固定金色 (212, 175, 55)

**脚本**：`_gen_batch_bg_v3.py`
