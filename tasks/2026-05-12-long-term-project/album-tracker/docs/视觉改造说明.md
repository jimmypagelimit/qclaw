# 拾音 · 私人唱片档案

2026-10-19。album-tracker 展示层改造。

## 视觉方向

以私人唱片档案与唱片内封为灵感，使用暖纸底色、墨黑、朱红、细线与留白。首页黑胶与封套由 CSS 绘制，不依赖远程图片或动画库。封面保持原貌，收藏页使用展陈式网格，详情页采用唱片内页式排版。

## 改动边界

仅修改 `public/index.html`，新增 `public/css/exhibition.css`。原有 `style.css` 保留，以独立样式层覆盖。未修改 `public/js/app.js`、`src/`、`dist/`、接口、数据库、曲目或歌词文件；原 DOM ID、事件入口、筛选选项与默认值全部保留。无需重新编译或重启服务，刷新页面即可。

增强手机布局、表格横向滚动、键盘焦点、控件可访问名称、跳转主内容入口、状态提示，以及 `prefers-reduced-motion` 支持。没有新增前端依赖；字体沿用原页面 Google Fonts 链接，并提供系统字体回退。

## 验证

使用本机 Chrome / Playwright 进行只读检查：概览与榜单、搜索与空结果、年份筛选、排序、卡片和列表视图、分页、详情开启关闭。320、390、768、1024、1440 像素布局未发现页面横向溢出。业务脚本、服务端入口与数据库 SHA-256 与改造前一致；统计 API 返回结果一致。

改造前后截图保存在 `/root/album-tracker-preview/`。

## 恢复旧版外观

从 `public/index.html` 移除 exhibition.css 的链接即可恢复原样式；若需连同标题、文案和装饰一并恢复，可从本次提交的父提交还原 `public/index.html`。无需对数据库进行任何操作。
