# 拾音 · 私人唱片档案

2026-10-19。album-tracker 展示层改造。

## 视觉方向

以私人唱片档案与唱片内封为灵感，使用暖纸底色、墨黑、朱红、细线与留白。首页黑胶与封套由 CSS 绘制，不依赖远程图片或动画库。封面保持原貌，收藏页使用展陈式网格，详情页采用唱片内页式排版。

## 改动边界

仅修改 `public/index.html`，新增 `public/css/exhibition.css`。原有 `style.css` 保留，以独立样式层覆盖。未修改 `public/js/app.js`、`src/`、`dist/`、接口、数据库、曲目或歌词文件；原 DOM ID、事件入口、筛选选项与默认值全部保留。无需重新编译或重启服务，刷新页面即可。

增强手机布局、表格横向滚动、键盘焦点、控件可访问名称、跳转主内容入口、状态提示，以及 `prefers-reduced-motion` 支持。没有新增前端依赖；字体沿用原页面 Google Fonts 链接，并提供系统字体回退。

## 验证

使用本机 Chrome / Playwright 进行只读检查：概览与榜单、搜索与空结果、年份筛选、排序、卡片和列表视图、分页、详情开启关闭。320、390、768、1024、1440 像素布局未发现页面横向溢出。业务脚本、服务端入口与数据库 SHA-256 与改造前一致；统计 API 返回结果一致。

改造前后截图保存在 `/root/album-tracker-preview/`。

## 恢复旧版外观

从 `public/index.html` 移除 exhibition.css 的链接即可恢复原样式；若需连同标题、文案和装饰一并恢复，可从本次提交的父提交还原 `public/index.html`。无需对数据库进行任何操作。

## 第二轮细节雕刻

保留第一轮视觉方向，仅调整 HTML 控件图标与展示样式；业务 JavaScript、服务端与数据库仍保持原样。

- 专辑标题最多显示两行，并固定标题区域高度；封面悬停显示内页提示、抬起阴影和朱红细线。触屏不依赖悬停。
- 黑胶高光、唱片封套折边与纸张色阶；装饰仅在精确指针悬停时轻微响应。
- 搜索和视图按钮采用一致的 SVG 线条；加强输入焦点、按压反馈，主要控件至少 44px 高。手机搜索输入为 16px。
- 详情开启时用 CSS 锁定背景滚动，保留页面滚动条占位；内部滚动不带动背景。长曲名可换行。
- 歌词时间标签使用等宽数字，正文更易读；LRC 块级行忽略源代码换行产生的额外空行，纯文本保留原换行。
- 搜索空结果提供更明确的视觉和查询建议；为数据加载预留部分空间。支持减少动画与系统强制颜色模式。

### 网上调研依据

- [NN/g：视觉设计五原则](https://www.nngroup.com/articles/principles-visual-design/)：比例、层次、平衡、对比与整体关系。用于统一文字、封面和留白。
- [NN/g：审美与可用性](https://www.nngroup.com/articles/aesthetic-usability-effect/)：视觉应服务操作，不能掩盖使用问题。保留原有流程并做浏览器回归。
- [W3C：目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：指针目标至少 24×24 CSS 像素，存在例外；本轮主要按钮采用更宽裕的 44px。
- [W3C：焦点外观](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html)：使用清晰可辨的焦点指示。此处不声明整站 WCAG 达标。
- [web.dev：高性能 CSS 动效](https://web.dev/articles/animations-guide)：优先使用 transform 和 opacity，实现克制的局部反馈。
- [web.dev：减少布局偏移](https://web.dev/articles/optimize-cls)：为异步内容预留空间，减少跳动。本轮未进行完整的 Core Web Vitals 现场测量。

## 第三轮：深入布局改造

保留既有配色与交互，新增独立 `public/css/layout.css`，调整 HTML 容器层级。未改动业务 JavaScript、后端和数据库。移除新增布局样式链接并恢复本轮 HTML 容器即可回到第二轮布局。

- 宽屏（≥1280px）使用固定左侧主导航，主区域独立铺展；平板和手机保留横向导航。
- 概览页改为主视觉与聆听统计侧栏。年度统计紧凑排列，唱片和艺术家榜首扩大展示；仍按现有接口排序，未添加精选或推荐算法。
- 收藏页改为左侧浏览索引与右侧唱片目录。查询、年份、排序、方向、视图等原有控件保留原 ID、默认值与事件；宽屏索引随滚动驻留，手机折叠为内容前方的查询区。
- 唱片墙按可用宽度展示 2–5 列，保持接口结果顺序及原分页数量。列表视图保留横向滚动。
- 详情改为展开内封：左侧封面、右侧资料，曲目、评分和歌词向下展开。手机单列，缺少封面时资料铺满；没有隐藏原有信息。

Chrome 只读回归覆盖 320/390/560/650/768/900/1024/1100/1279/1280/1440/1600/1920px，重点检查布局断点和导航切换。验证搜索、年份、排序、空结果、卡片/列表、分页、详情和歌词；控件不小于 44px，无页面或弹窗横向溢出，无脚本错误或写请求。原 DOM ID、业务脚本、后端、数据库与统计 API 均保持一致。
