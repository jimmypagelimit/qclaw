## 二、功能详细设计

### 2.1 维护模块 (manage)

#### 2.1.1 添加专辑 (`add`)
```bash
node dist/cli.js add --album "专辑名" --artist "艺术家" [其他字段...]
```

**必填：** album_name, artist  
**可选：**
```
--genre "风格"
--country "国家"
--region "地区"
--year "发行年份"
--style "风格细分"
--rating 8.5
--description "描述"
--is-compilation 0/1
--release-company "发行公司"
--producer "制作人"
```

**行为：**
- 插入到 `albums` 表
- `total_listen_count` 默认 1
- `first_listen_date` 默认为今天
- `album_id` 自增

#### 2.1.2 编辑专辑 (`edit`)
```bash
node dist/cli.js edit --id 123 --field value [--field value...]
```

**可编辑字段：** 除 album_id 外的所有字段

**行为：**
- 按 album_id 查找
- 更新指定字段
- 显示更新前后的值

#### 2.1.3 删除专辑 (`delete`)
```bash
node dist/cli.js delete --id 123 [--confirm]
```

**行为：**
- 无 `--confirm` 时显示预览（"将删除：xxx"）
- 有 `--confirm` 时执行删除
- 同时删除 albums_2024/2025/2026 中的关联记录（如果有）

#### 2.1.4 记录收听 (`listen`)
```bash
node dist/cli.js listen --id 123 [--count 1]
```

**行为：**
- `total_listen_count` += count
- `first_listen_date` 如果为空则设为今天
- 显示更新后的总次数

#### 2.1.5 批量添加年份标签 (`tag-year`)
```bash
node dist/cli.js tag-year --year 2024
```

**行为：**
- 将 albums 表中 `first_listen_date` 在 2024 年的记录复制到 albums_2024 表

### 2.4 导入导出模块 (data)

#### 2.4.1 导出为 CSV (`export-csv`)
```bash
node dist/cli.js export --format csv --output exports/albums_2024.csv
```

**行为：**
- 支持 `--table albums|albums_2024|albums_2025|albums_2026`
- 默认导出 albums 表
- UTF-8 编码，Windows Excel 兼容

#### 2.4.2 导出为 JSON (`export-json`)
```bash
node dist/cli.js export --format json --output exports/albums_2024.json
```

#### 2.4.3 从 CSV 导入 (`import-csv`)
```bash
node dist/cli.js import --format csv --file imports/new_albums.csv [--table albums]
```

**行为：**
- 支持字段映射
- 重复检测（按 album_name + artist）
- 可选：重复时跳过 / 更新 / 报错

## 八、数据同步工作流程（已确认 2026-05-12）

### 8.1 数据源
| 数据源 | 路径 | 格式 |
|--------|------|------|
| Markdown 听歌记录 | `G:\diary-content\history\music\2026\` | RYM 格式 Markdown |
| SQLite 数据库 | `G:\原创计划\music` | 结构化数据库 |

### 8.2 Markdown 文件结构
```
G:\diary-content\history\music\2026\
├── 华语新/  # 1月.md, 2月.md, 3月.md, 4月.md, 5月.md...
├── 华语旧/
├── 外语新/
└── 外语旧/  # 1月.md, 2月.md, 3月.md, 4月.md...
```

### 8.3 新建 Markdown 月度文件的流程

#### Step 1: 创建文件（如 5月.md）
```python
content = """# 5月听歌记录

 * 《春子 Haruko》 - L8ching 1
    >  春子 Haruko
        Artist\tL8ching
        Type\tAlbum
        Released\t1 May 2026
        RYM Rating\t3.00 / 5.0 from 4 ratings
        Genres\t
        Descriptors\t
        Language\tChinese
"""
with open(r'G:\diary-content\history\music\2026\华语新\5月.md', 'w', encoding='utf-8') as f:
    f.write(content)
```

#### Step 2: 验证文件内容
```bash
cat 'G:/diary-content/history/music/2026/华语新/5月.md'
```

#### Step 3: 如需同步到 SQLite，生成 SQL 语句
- 判重：`SELECT * FROM albums WHERE album_name = '...' AND artist = '...'`
- 不存在 → INSERT
- 已存在 → UPDATE total_listen_count

#### Step 4: 执行 SQL 入库

### 8.3 记录格式

**复杂格式（来自 RYM）：**
```markdown
# * 《Teens of Denial》 - Car Seat Headrest 2
    >  Teens of Denial
        Artist	Car Seat Headrest
        Released	20 May 2016
        Genres	Indie Rock
        Language	English
```

**简单格式：**
```markdown
* 《Album Name》 - Artist 1
```

### 8.4 数据表说明

| 表名 | 说明 |
|------|------|
| `albums` | **所有年份的完整汇总**（不是早期数据） |
| `albums_2024` | 2024年收听记录（方便查年度排行） |
| `albums_2025` | 2025年收听记录 |
| `albums_2026` | 2026年收听记录 |

**统计规则：**
- 总排行 → 查 `albums` 表
- 年度排行 → 查 `albums_YYYY` 表

### 8.5 同步方式（手动，不写代码）

**流程：** 用户发 Markdown 记录 → 我生成 SQL/CLI 命令 → 帮用户执行入库

**判重依据：** `album_name` + `artist` 组合唯一

**同步规则：**
| 情况 | 处理方式 |
|------|----------|
| 专辑不存在 | 新增记录 |
| 专辑已存在 | **只增加** `total_listen_count` |

**操作方式：**
```bash
# 方式1：用 CLI 命令
node dist/cli.js sync --file "华语新/5月.md"

# 方式2：直接执行 SQL
sqlite3 music "UPDATE albums SET total_listen_count = total_listen_count + X WHERE album_name = '...' AND artist = '...';"
```
