# 匿名旅行者API对接与李杰专辑数据修正

## 目标
用匿名旅行者(anontraveler.com)补充李杰《谁都看见了希望》的专辑数据

## 关键发现

### 匿名旅行者API
- **搜索API**: `GET /api/meta/quick_search/all?kw=xxx`（需URL编码中文）
- **专辑详情API**: `GET /api/meta/album/{album_id}`
- **搜索限制**: 短关键词（如"李杰"）可能返回空，需用完整专辑名搜索
- **SPA架构**: Vue 3，`page.fill()` 可触发搜索但API返回更精确

### 数据修正
- **album_id=51** 原有11首错误曲目（粤语歌，疑似另一张同名专辑），已替换为匿名旅行者的9首正确曲目
- 新增 description（含风格、评分、郭佳短评）
- 新增 external_ratings: anontraveler 94/100

### 李杰《谁都看见了希望》专辑数据
- 年份：1998，类型：录音室专辑
- 风格：艺术摇滚/前卫摇滚、另类/独立流行/摇滚、民族融合
- 匿名旅行者评分：94/100
- 网易云ID：11805
- 曲目：9首（笑容→谁都看见了希望）
- 郭佳评："大陆新音乐运动的技术性最高峰作品"
- GENTOVA 90年代最佳专辑第9位（9.4分）
- 石田吉藏 华语最佳500张 第8位

## 决策
- 匿名旅行者API可用于后续专辑数据补充（尤其中文专辑）
- 需通过Playwright浏览器上下文调API（需先visit站点获取session）
